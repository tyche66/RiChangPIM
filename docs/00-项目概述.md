# 00 - 项目概述

## 一、项目背景

### 1.1 行业痛点

企业在产品信息管理过程中长期面临三大核心痛点：

- **资产沉淀缺失**：产品资料、说明书散落在各处，无序化存储，版本与权限管理混乱，知识无法沉淀复用。
- **效能流转低下**：销售新人培训成本高，产品推荐、方案整理、报价单维护与对外分享效率低，严重依赖个人经验。
- **数据耦合严重**：传统业务逻辑与大模型能力混杂，AI 直接输出价格、库存等敏感数据，准确性无法保障。

### 1.2 项目定位

AI-PIM 定位为 **AI 驱动的企业级产品信息管理平台**。它不仅是一个 AI 聊天机器人，而是以 **Business API 为核心**，将产品管理、供应商管理、报价管理、方案生成等传统 PIM 功能，与可插拔的 AI 能力中心深度融合的现代化企业基础软件。

核心设计原则：**业务逻辑由数据库与 Business API 维护，AI 只负责理解、生成与推荐，所有业务统一走 Business API。**

### 1.3 商业价值

| 价值维度 | 具体体现 |
| --- | --- |
| 资产沉淀 | 产品资料结构化归档，知识库可复用，版本权限统一管理 |
| 效能提升 | 销售新人快速上手，产品推荐/方案/报价一键生成，对外分享安全高效 |
| 数据可信 | 业务数据与 AI 能力彻底解耦，核心数据绝对真实，AI 理解能力充分释放 |
| 架构灵活 | AI 引擎可插拔（FastGPT/Dify/RagFlow），切换零改造业务层 |
| 低成本演进 | 依赖开源组件，私有化部署，预算可控，长期维护成本低 |

## 二、核心解决场景

### 2.1 产品资产数字化归档

管理员上传产品结构化数据与 PDF 说明书，系统通过 MinerU OCR 自动解析，双写入库（业务库 + 向量知识库），人工校验后一键上架。

### 2.2 AI 智能产品推荐

客户/销售输入模糊需求（如"预算5万、现代风、30人会议室投影设备"），AI 理解意图后转化为标准化筛选条件，调用 Business API 精准匹配，结果经 AI 润色后结构化呈现。

### 2.3 销售方案一键生成与分享

销售勾选产品组合，系统自动生成基础方案，AI 执行商务语境润色与推荐理由生成，分享中心一键导出 PDF/生成 H5 与二维码，客户手机扫码查阅（带权限校验）。

## 三、技术选型总览

| 层次 | 技术选型 | 选型理由 |
| --- | --- | --- |
| 表现层 | Vue3 + Vite + Element Plus + Pinia | 主流前端栈，生态成熟，H5 与管理后台共享组件 |
| 业务层 | FastAPI (Python) | 异步高性能，自动生成 OpenAPI 文档，与 AI 生态同语言 |
| 服务层 | MinerU (OCR) + Gotenberg (PDF) + AI Service Adapter | 开源原子服务，AI 适配器实现引擎可插拔 |
| 基础设施 | PostgreSQL + pgvector + Redis + MinIO + Docker | 关系库+向量扩展一体化，私有化对象存储，容器化部署 |

## 四、MVP 交付标准

### 4.1 MVP 核心链路

MVP 聚焦打通 **"产品录入 → 方案生成 → H5 分享"** 这条核心销售链路，优先验证业务价值。

> ⚠ RAG 说明书问答从 MVP 移到 V1，避免 MVP 范围过大影响交付质量。

### 4.2 MVP 功能范围

| 模块 | MVP 必须交付 | 延后到 V1+ |
| --- | --- | --- |
| 用户与权限 | 用户管理、RBAC 基础权限（单角色 RBAC） | 字段级权限精细化 |
| 产品中心 | 产品 CRUD、分类管理、Excel 导入导出 | 一键克隆、批量上下架 |
| 方案中心 | 勾选产品生成方案、基础明细 | AI 润色、推荐理由 |
| 分享中心 | H5 分享 + 二维码 + 基础访问控制 | 密码保护、到期失效、次数限制 |
| AI 能力中心 | — | RAG 问答、智能推荐、文案生成 |
| 报价中心 | — | 动态报价单、PDF 导出 |

> **MVP 建表策略说明**：
> MVP 阶段虽仅交付核心功能，但 23 张数据表在 MVP 全部建表（含 V1 才启用的 share_token、ai_conversation、visitor 等表）。
> 理由：
> 1. 避免后续阶段频繁 DDL 迁移风险
> 2. 表结构是契约，提前建表有助于前后端并行开发
> 3. 未启用的表不产生数据，无性能影响
>
> 各表的功能启用时点以本表"阶段"列为准，与建表时点解耦。

### 4.3 MVP 验收标准

1. 管理员可完成产品录入、分类管理、Excel 批量导入
2. 销售可勾选产品生成方案并查看明细
3. 销售可生成分享链接与二维码，客户扫码可查阅 H5 方案
4. 基础 RBAC 权限生效（销售/管理员角色隔离）
5. 系统可通过 Docker Compose 一键部署启动

---

## 五、系统边界（不做什么）

本系统**不属于** ERP、MES、CRM 或财务软件：

- ❌ 不处理复杂的财务对账
- ❌ 不管理生产制造工序
- ❌ 不做多级客户生命周期管理
- ✅ 通过标准 REST API 与企业现有钉钉、企业微信、外部 CRM 等系统解耦式集成
