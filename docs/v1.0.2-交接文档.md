## 2. v1.0.2 交付摘要

### 修复内容

- **分享页图片不显示**：修复分享给客户的方案/报价页面中，产品封面图和场景图全部无法显示的问题。

### 根因

分享接口 `GET /api/v1/share/{token}` 原直接返回 MinIO 预签名 URL（如 `http://minio:9000/ai-pim/...?signature=...`），生产/容器网络下浏览器无法解析 `minio` 容器名，也无端口映射可达 9000 端口。

### 修复方案

复用现有后端代理链路 `/api/v1/files/{id}/content?token=...`（同普通页面），将分享页所有图片 URL 改为相对代理路径，经 nginx → backend:8000 → MinIO 流式返回。

### 关键变更文件

| 文件 | 变更说明 |
|---|---|
| `backend/app/api/v1/share_token.py` | 移除 `_calc_image_expire_seconds`、`_fetch_presigned_urls` 及 `minio_client`/`settings` 依赖；新增 `_create_share_content_url()` 生成 15 分钟有效的 `file_content` scope JWT；`_fetch_content_urls()` 仅为有效附件生成代理 URL；`_build_content()` 不再接收 `ShareToken`、不再计算过期秒数；公开接口 `GET /share/{token}` 调用链不变。 |
| `backend/tests/test_share_token.py` | 新增纯单元测试 `test_share_content_url_uses_backend_proxy`，校验生成 URL 以 `/api/v1/files/.../content?token=` 开头、不含 `minio`、token 解码后 `scope=file_content` 且 `attachment_id` 匹配。 |
| `frontend/src/views/SharePage.vue` | 无需变更，直接复用 `row.cover_image_url` 与 `scene.image_url` 作为 `<img src>`。 |
| `docker/nginx/nginx.conf` | 无需变更，已代理 `/api/` 至 `backend:8000`。 |

## 5. 业务状态规则

### 方案

| 当前状态 | 操作 | 结果 |
|---|---|---|
| `draft` | 编辑 | 允许 |
| `draft` | 确认 | 必须有至少一个有效明细，然后变为 `confirmed` |
| `confirmed` | 编辑 | 禁止 |
| `confirmed` | 撤销确认 | 无 confirmed 报价时变为 `draft` |
| `draft` 或 `confirmed` | 生成报价 | 允许 |
| `draft` 或 `confirmed` | 分享方案 | 按当前分享规则允许 |

### 报价

| 当前状态 | 操作 | 结果 |
|---|---|---|
| `draft` | 编辑 | 允许 |
| `draft` | 确认 | 必须有至少一个有效明细，然后变为 `confirmed` |
| `confirmed` | 编辑 | 禁止 |
| `draft` | 分享 | 禁止 |
| `confirmed` | 分享 | 允许 |

产品可销售条件统一为：`status == active` 且 `is_deleted == false`。库存状态只作为展示信息，不阻止销售。

## 6. 金额规则

### 方案

```text
方案行面价 = face_price × quantity
方案总面价 = 所有方案行面价之和
```

### 报价

```text
报价行未税小计 = unit_price × quantity
报价行含税金额 = 报价行未税小计 × (1 + tax_rate)
报价未税小计 = 所有报价行未税小计之和
报价最终金额 = sum(报价行含税金额) × discount
```

- `tax_rate` 和 `discount` 均为 0 到 1 的小数，例如 13% 使用 `0.13`。
- `discount` 是报价整单字段，不属于报价明细。
- 后端重新计算 subtotal、total_amount 和 total_face_value，不信任前端传入金额。
- 后端统一四舍五入到 2 位小数。
- PDF、报价详情、前端报价编辑页和匿名分享页必须遵循同一规则。

## 7. 关键 API

API 前缀：`/api/v1`

### 方案

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| `GET` | `/proposals` | `proposal:view` | 关键词、状态和分页查询 |
| `GET` | `/proposals/{id}` | `proposal:view` | 详情，返回富化产品明细 |
| `POST` | `/proposals` | `proposal:create` | 创建非空方案 |
| `PUT` | `/proposals/{id}` | `proposal:edit` | 更新草稿方案 |
| `POST` | `/proposals/{id}/confirm` | `proposal:confirm` | 确认方案 |
| `POST` | `/proposals/{id}/revert-confirmation` | `proposal:edit` | 撤销确认 |
| `DELETE` | `/proposals/{id}` | `proposal:delete` | 软删除 |

正式响应使用：

```json
{
  "code": 200,
  "data": {}
}
```

方案详情明细包含 `id`、`product_id`、`product_no`、`product_name`、`face_price`、`quantity`、`remark`、`line_total` 和 `cover_image_url`。

### 报价

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/quotations` | 报价分页列表，可按方案和状态筛选 |
| `GET` | `/quotations/{id}` | 报价详情和富化明细 |
| `POST` | `/quotations` | 创建报价 |
| `PUT` | `/quotations/{id}` | 更新草稿报价 |
| `POST` | `/quotations/{id}/confirm` | 确认报价 |
| `GET` | `/quotations/{id}/pdf` | 生成报价 PDF 任务 |

报价明细必须满足：`quantity >= 1`、`unit_price >= 0`、`0 <= tax_rate <= 1`。整单 `discount` 必须在 0 到 1 之间。

### 分享

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/shares` | 创建方案或报价分享 |
| `GET` | `/shares` | 分享管理列表 |
| `DELETE` | `/shares/{id}` | 删除分享 |
| `GET` | `/share/{token}` | **匿名读取分享内容（图片为后端代理 URL）** |

分享 URL 优先使用 `VITE_PUBLIC_FRONTEND_URL`，未配置时使用当前前端 origin。二维码在前端本地使用 `qrcode` 生成，不调用在线二维码服务。

## 12. 常见问题排查

### 分享页图片不显示

1. 检查浏览器 Network 中图片请求 URL 是否为 `/api/v1/files/{id}/content?token=...`（而非 `http://minio:9000/...`）。
2. 若仍为 MinIO 直连 URL，确认后端 `share_token.py` 已更新至 v1.0.2 版本（含 `_create_share_content_url`）。
3. 检查后端日志：`docker compose logs --tail=200 backend`，搜索 `share_content_url` 或 `_fetch_content_urls`。
4. 确认 nginx 代理 `/api/` → `backend:8000` 正常（`docker compose logs nginx`）。
5. 重新构建并重建后端、nginx：
   ```bash
   docker compose build backend
   docker compose up -d backend nginx
   ```

### 点击方案显示“加载方案详情失败”

1. 检查浏览器 Network 中 `GET /api/v1/proposals/{id}` 的状态码。
2. 确认响应是 `{code, data}`，而不是错误页或 401/403。
3. 查看后端日志：`docker compose logs --tail=200 backend`。
4. 重新构建并重建后端，排除前端源码和运行容器版本漂移：
   ```bash
   docker compose build backend
   docker compose up -d backend nginx
   ```

### 登录 500 或数据库认证失败

- 检查 `.env` 中 `POSTGRES_PASSWORD` 与数据库实际初始化密码是否一致。
- 后端 `DATABASE_URL` 使用同一个密码。
- 只修改环境变量后必须重建/重启相关容器。
- 如果是已经存在的 PostgreSQL volume，修改 `.env` 不会自动修改数据库已有用户密码，需要按运维流程处理。

### 前端看不到最新代码

- 确认 `frontend/dist` 已重新生成。
- 确认 Nginx 挂载的是当前项目的 `frontend/dist`。
- 清理浏览器缓存或使用强制刷新。
- 检查 Nginx 容器是否已重启。

### Docker 测试出现重复模块收集错误

不要把测试目录复制成 `/app/tests/tests`。正确的临时复制方式是复制测试目录内容到 `/app/tests/`，或者直接重建不包含测试目录的生产镜像。
