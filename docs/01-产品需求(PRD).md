# 01 - 产品需求文档（PRD）

> 本文档基于概念方案第五章"系统模块与功能清单"细化展开，覆盖核心业务功能点、页面交互逻辑与角色权限场景。

---

## 一、用户角色定义

| 角色 | 使用场景 | 权限范围 |
| --- | --- | --- |
| **系统管理员** | 系统配置、用户与角色管理 | 全部模块读写 |
| **采购/产品经理** | 产品参数配置、成本价维护、供应商管理 | 产品/供应商/品牌/分类读写；**可见成本价** |
| **销售** | 产品检索、方案生成、报价、分享 | 产品参数读；AI 推荐/方案/报价读写；**严禁查看成本价** |
| **外部客户** | H5 分享页面只读查阅 | 无需登录；仅被分享内容的只读权限 |

> **角色演进路线**：
> - **MVP / V1**：单角色模型（user.role_id 外键），一个用户绑定一个角色，满足当前业务场景
> - **V2+**：多角色模型（新增 user_role 关联表），支持一个用户兼任多角色（如同时是销售和采购）
> - 03-ERD 的 user 表已预留此演进，V2 阶段新增 user_role 表并移除 role_id NOT NULL 约束

## 二、用户与权限中心（RBAC）

### 2.1 功能清单

| 功能点 | 说明 | 阶段 |
| --- | --- | --- |
| 用户管理 | 账号创建、停用、角色分配 | MVP |
| 角色管理 | 角色 CRUD、角色绑定权限。MVP 阶段单角色（user.role_id），V2 多租户阶段演进为多角色（新增 user_role 关联表） | MVP |
| 菜单权限 | 控制前端菜单可见性 | MVP |
| 按钮权限 | 控制页面操作按钮可见性 | MVP |
| 接口权限 | API 级别访问控制（JWT + 权限码） | MVP |
| 字段级权限 | 敏感字段响应层过滤（如 `cost_price`、`supplier_id`） | V1 |

> **角色绑定演进说明**：MVP/V1 阶段采用单角色模型（user.role_id 外键 NOT NULL），一个用户仅绑定一个角色，已满足当前业务场景；V2 多租户阶段演进为多角色模型，新增 user_role 关联表并移除 role_id 的 NOT NULL 约束，权限取并集。字段级权限矩阵（见 appendix/权限矩阵.md）按角色定义，与角色绑定模型无关。

### 2.2 字段级权限实现要求

- 在 FastAPI 响应序列化层做统一过滤，避免通过 ORM 查询直接泄露
- 在接口层或服务层对字段级权限进行兜底校验
- 形成 **"查询层 + 响应层"** 双重防线

### 2.3 经典隔离场景

- **销售角色**：可查看产品参数、AI 推荐、方案生成，**严禁查看成本价**
- **采购/产品经理**：可配置产品参数、维护成本价与供应商链条
- **外部客户**：无需登录，仅拥有被分享 H5 页面的只读权限

> 详细字段级权限矩阵见 [appendix/权限矩阵](./appendix/权限矩阵.md)。

> **产品属性扩展评估**：
> 当前 MVP 产品表包含：编号、名称、品牌、供应商、分类、面价、成本价、材质、库存状态、多媒体文件。
> 以下常见属性评估后**不在 MVP 纳入**，按需在 V1 扩展：
> - 重量/尺寸/颜色：通过 material 字段或标签体系覆盖
> - 保修期：可通过说明书 PDF 承载
> - 自定义属性：V1 评估是否引入 EAV 模型或 JSONB 扩展字段
>
> MVP 保持字段精简，避免过度设计影响交付节奏。

## 四、AI 能力中心

### 4.1 核心应用场景

| 场景 | 说明 | 阶段 |
| --- | --- | --- |
| 文档知识检索（RAG） | 解析产品说明书/技术参数表，回答技术硬指标问题 | V1 |
| 产品智能推荐 | 理解模糊意图 → 转标准化筛选条件 → 调 Business API 精准匹配 | V1 |
| AI 方案生成与润色 | 对产品组合进行亮点提炼、行业话术修饰、推荐理由生成 | V1 |
| AI 营销文案生成 | 多渠道文案（小红书/朋友圈/SEO/短视频脚本） | V2 |
| AI 销售与培训助手 | 解答产品竞争优势与区别，赋能内部员工 | V2 |

### 4.2 AI 能力红线

> ⚠ AI 能力中心**永远不负责**价格、库存、供应商、客户隐私等强准确性数据的维护。  
> 大模型只负责"理解与生成"，真实数据必须由 Business API 从关系型数据库实时调取。

### 4.3 数据流边界

- 向量召回只负责提供"候选集"，不能直接作为最终事实数据输出
- 强准确性字段必须由 Business API 再次查询数据库二次确认
- "向量召回结果 + 业务字段回查"作为统一执行链路

### 7.1 产品录入流程

```
管理员进入产品列表 → 点击"新增产品"
  → 填写基础信息（编号/名称/品牌/分类/面价/成本价）
  → 上传多媒体文件（图片/视频/说明书PDF）
  → 选择标签、关联供应商
  → 保存草稿 / 提交上架
```

### 7.2 AI 智能推荐交互

```
销售进入"AI 选品"页面 → 输入自然语言需求
  → AI 实时流式返回（SSE）意图拆解过程
  → 展示标准化筛选条件（可编辑修正）
  → 点击"查询" → Business API 返回匹配产品列表
  → AI 生成推荐话术 → 结构化呈现
```

### 7.3 方案生成与分享交互

```
销售进入产品列表 → 勾选产品 A/B/C → 点击"生成方案"
  → 方案中心自动组装明细 + 拉取物料
  → [V1] 点击"AI 润色" → 生成推荐理由与话术
  → 点击"分享" → 生成 H5 链接 + 二维码
  → [V1] 配置访问控制（密码/到期/次数）
  → 复制链接或下载二维码分享给客户
```
