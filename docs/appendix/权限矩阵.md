## 六、权限实现层说明

### 6.1 双重防线机制

```
请求 → 接口层权限校验（API 级别）
         ↓
      服务层权限校验（资源级别，如"是否本人方案"）
         ↓
      查询层权限过滤（SQL 级别，不查敏感字段）    ← 第一道防线
         ↓
      响应序列化层过滤（Pydantic 级别，剔除敏感字段） ← 第二道防线
         ↓
      返回响应
```

### 6.2 实现要点

- **查询层**：在 ORM 查询时根据角色动态选择字段（`load_only` / `defer`）
- **响应层**：在 Pydantic Schema 序列化时根据角色动态排除字段
- **兜底校验**：即使绕过查询层，响应层仍会过滤，确保敏感字段不泄露
