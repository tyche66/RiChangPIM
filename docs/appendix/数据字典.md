# 附录 - 数据字典

> AI-PIM 核心数据表字段定义字典。

---

## 一、业务表通用字段

> 以下字段为业务表共有。追加写日志/分析型表（share_log / operation_log / ai_conversation / visitor）不含 `deleted_at` / `is_deleted`，详见 1.1。

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | UUID v7 | 是 | 自动生成 | 主键 |
| create_time | TIMESTAMPTZ | 是 | now() | 创建时间 |
| update_time | TIMESTAMPTZ | 是 | now() | 更新时间（触发器自动更新） |
| deleted_at | TIMESTAMPTZ | 否 | NULL | 删除时间戳，NULL 表示未删除 |
| is_deleted | BOOLEAN | 是 | false | 软删除标记 |

### 1.1 追加写表字段规约

以下 4 张表为追加写日志/分析型数据，**不含** `deleted_at` / `is_deleted` 字段，不做软删除：

| 表名 | 类型 | 不含软删除字段的原因 |
| --- | --- | --- |
| share_log | 访问审计日志 | 追加写日志，访问记录需完整保留供审计追溯 |
| operation_log | 系统操作日志 | 追加写日志，操作记录需完整保留供审计追溯 |
| ai_conversation | AI 对话上下文 | 追加写日志，对话历史由 session 管理生命周期 |
| visitor | 访客表 | 分析型数据，访客记录用于长期画像分析，不做删除 |

> 注：visitor 表保留 `create_time` / `update_time`，但不含 `deleted_at` / `is_deleted`；其余 3 张日志表仅保留 `create_time`（或 `operate_time` / `access_time`）。详见各表字段定义。

## 二、用户与权限域

### User（用户表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | VARCHAR(64) | 是 | 用户名，唯一 |
| password_hash | VARCHAR(255) | 是 | bcrypt 加密密码 |
| email | VARCHAR(128) | 否 | 邮箱 |
| phone | VARCHAR(20) | 否 | 手机号 |
| status | VARCHAR(20) | 是 | active / disabled |
| role_id | UUID | 是 | 角色 ID（外键 → Role） |
| last_login_time | TIMESTAMPTZ | 否 | 最后登录时间 |

### Role（角色表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| role_name | VARCHAR(64) | 是 | 角色名称 |
| role_code | VARCHAR(32) | 是 | 角色编码（admin/purchaser/sales） |
| description | VARCHAR(255) | 否 | 角色描述 |

### Permission（权限表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| perm_code | VARCHAR(64) | 是 | 权限编码 |
| perm_name | VARCHAR(64) | 是 | 权限名称 |
| resource | VARCHAR(64) | 是 | 资源标识（如 product） |
| action | VARCHAR(32) | 是 | 操作（read/write/delete） |
| type | VARCHAR(20) | 是 | menu / button / api / field |

### RolePermission（角色权限关联表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| role_id | UUID | 是 | 角色 ID（外键 → Role） |
| permission_id | UUID | 是 | 权限 ID（外键 → Permission） |

> 联合唯一约束：(role_id, permission_id)，防止重复授权。

## 三、产品核心域

### Product（产品主表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| product_no | VARCHAR(64) | 是 | 产品编号，唯一 |
| product_name | VARCHAR(255) | 是 | 产品名称 |
| brand_id | UUID | 是 | 品牌 ID（外键 → Brand） |
| supplier_id | UUID | 是 | 供应商 ID（外键 → Supplier） |
| category_id | UUID | 是 | 分类 ID（外键 → Category） |
| face_price | DECIMAL(12,2) | 是 | 面价 |
| cost_price | DECIMAL(12,2) | 否 | 成本价（字段级权限屏蔽销售） |
| material | VARCHAR(128) | 否 | 材质 |
| stock_status | VARCHAR(20) | 是 | in_stock / out_of_stock / preorder |
| status | VARCHAR(20) | 是 | active / inactive / draft |
| vector | vector(1536) | 否 | 向量字段（pgvector，系统维护） |

### Category（分类树形表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| parent_id | UUID | 否 | 父分类 ID，NULL 为根节点 |
| level | INT | 是 | 层级（1/2/3） |
| category_name | VARCHAR(128) | 是 | 分类名称 |
| sort | INT | 是 | 排序序号 |

### Tag（标签表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| tag_name | VARCHAR(64) | 是 | 标签名称 |
| tag_type | VARCHAR(32) | 否 | 标签类型（如 style/scene/function） |

### Brand（品牌表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| brand_name | VARCHAR(128) | 是 | 品牌名称 |
| logo_url | VARCHAR(512) | 否 | Logo 地址 |
| description | TEXT | 否 | 品牌描述 |

### Supplier（供应商表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| supplier_name | VARCHAR(128) | 是 | 供应商名称 |
| contact | VARCHAR(64) | 否 | 联系人 |
| phone | VARCHAR(20) | 否 | 联系电话 |
| cooperation_status | VARCHAR(20) | 是 | active / suspended / terminated |

### ProductTag（产品标签中间表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| product_id | UUID | 是 | 产品 ID（外键 → Product） |
| tag_id | UUID | 是 | 标签 ID（外键 → Tag） |

> 联合唯一约束：(product_id, tag_id)。本表无软删除字段，随产品级联删除。

## 五、销售交易域

### Proposal（方案主表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| proposal_no | VARCHAR(64) | 是 | 方案编号，唯一 |
| proposal_name | VARCHAR(255) | 是 | 方案名称 |
| creator_id | UUID | 是 | 创建人 ID（外键 → User） |
| customer_name | VARCHAR(128) | 否 | 客户名称 |
| status | VARCHAR(20) | 是 | draft / confirmed / archived |
| ai_polished | BOOLEAN | 是 | 是否已 AI 润色，默认 false |
| total_face_value | DECIMAL(14,2) | 是 | 面价合计，便于列表展示，由后端在明细变更时重算，默认 0 |

### ProposalItem（方案明细表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| proposal_id | UUID | 是 | 方案 ID（外键 → Proposal） |
| product_id | UUID | 是 | 产品 ID（外键 → Product） |
| quantity | INT | 是 | 数量 |
| sort | INT | 是 | 排序 |
| remark | TEXT | 否 | 备注 |

### Quotation（报价单表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| quotation_no | VARCHAR(64) | 是 | 报价单编号，唯一 |
| proposal_id | UUID | 是 | 关联方案 ID（外键 → Proposal） |
| creator_id | UUID | 是 | 创建人 ID（外键 → User） |
| valid_until | TIMESTAMPTZ | 否 | 报价有效期，NULL 表示长期有效 |
| total_amount | DECIMAL(14,2) | 是 | 总价 |
| tax_rate | DECIMAL(5,4) | 是 | 税率（如 0.13） |
| discount | DECIMAL(5,4) | 否 | 折扣（如 0.95） |
| status | VARCHAR(20) | 是 | draft / confirmed / expired |

### QuotationItem（报价单明细表）

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| quotation_id | UUID | 是 | - | 报价单 ID（外键 → Quotation） |
| product_id | UUID | 是 | - | 产品 ID（外键 → Product） |
| quantity | INT | 是 | 1 | 数量，必须 > 0 |
| unit_price | DECIMAL(12,2) | 是 | - | 单价（快照，下单时锁定） |
| tax_rate | DECIMAL(5,4) | 是 | 0.13 | 税率 |
| subtotal | DECIMAL(14,2) | 是 | - | 小计 = quantity × unit_price × (1+tax_rate) |

> 随报价单级联删除。unit_price 为快照值，产品价格变动不影响已生成报价单。

## 六、流转与审计域

### Share（对外分享配置表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| share_type | VARCHAR(20) | 是 | proposal / quotation |
| target_id | UUID | 是 | 分享对象 ID |
| creator_id | UUID | 是 | 创建人 ID |
| status | VARCHAR(20) | 是 | active / disabled |

### ShareToken（分享凭证表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| share_id | UUID | 是 | 关联 Share ID |
| token | VARCHAR(64) | 是 | 唯一访问令牌 |
| password | VARCHAR(255) | 否 | 访问密码（bcrypt），NULL 表示无密码 |
| expire_time | TIMESTAMPTZ | 否 | 过期时间，NULL 表示永不过期 |
| max_access_count | INT | 否 | 最大访问次数，NULL 表示不限 |
| current_access_count | INT | 是 | 当前已访问次数，默认 0 |
| status | VARCHAR(20) | 是 | active / expired / disabled |

### ShareLog（分享访问审计表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| share_token_id | UUID | 是 | 关联 ShareToken ID |
| visitor_id | UUID | 否 | 关联访客 ID（外键 → Visitor，未识别时为空） |
| visitor_ip | VARCHAR(64) | 否 | 访问者 IP |
| visitor_ua | VARCHAR(512) | 否 | 访问者 User-Agent |
| device_fingerprint | VARCHAR(128) | 否 | 设备指纹（前端 FingerprintJS 生成） |
| openid | VARCHAR(64) | 否 | 微信 openid（接入微信后填充，快照值） |
| access_time | TIMESTAMPTZ | 是 | 访问时间 |
| access_result | VARCHAR(20) | 是 | success / denied_password / denied_expired / denied_count |

### OperationLog（系统操作日志表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| user_id | UUID | 是 | 操作人 ID |
| module | VARCHAR(64) | 是 | 操作模块 |
| action | VARCHAR(32) | 是 | 操作动作（create/update/delete/share） |
| target_id | UUID | 否 | 操作目标 ID |
| request_body | TEXT | 否 | 请求体摘要 |
| response_code | INT | 是 | 响应码 |
| ip | VARCHAR(64) | 否 | 操作 IP |
| operate_time | TIMESTAMPTZ | 是 | 操作时间 |

### AIConversation（AI 交互对话上下文表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| session_id | VARCHAR(64) | 是 | 会话唯一标识 |
| user_id | UUID | 是 | 用户 ID |
| question | TEXT | 是 | 用户问题 |
| answer | TEXT | 否 | AI 回答 |
| sources | JSON | 否 | 引用来源列表 |
| tool_calls | JSON | 否 | 标准化 Tool Call 列表 |

### Visitor（访客表）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| fingerprint | VARCHAR(128) | 否 | 设备指纹（前端 FingerprintJS 生成） |
| openid | VARCHAR(64) | 否 | 微信 openid（唯一，精准标识） |
| unionid | VARCHAR(64) | 否 | 微信 unionid（跨公众号/小程序统一） |
| nickname | VARCHAR(128) | 否 | 微信昵称 |
| avatar_url | VARCHAR(512) | 否 | 微信头像 URL |
| first_seen_time | TIMESTAMPTZ | 是 | 首次访问时间 |
| last_seen_time | TIMESTAMPTZ | 是 | 最近访问时间 |

> 本表不含软删除字段，访客记录为分析型数据，不做删除。openid 唯一索引（非空时）。
