# 附录 - 名词解释

> AI-PIM 项目术语表，涵盖业务概念与技术名词。

---

## 业务术语

| 术语 | 英文 | 释义 |
| --- | --- | --- |
| PIM | Product Information Management | 产品信息管理，企业级产品主数据管理平台 |
| RBAC | Role-Based Access Control | 基于角色的访问控制，通过角色分配权限 |
| 方案 | Proposal | 销售向客户推荐的产品组合方案，含明细与物料 |
| 报价单 | Quotation | 基于方案生成的动态报价文档，含税率/折扣/总价 |
| 面价 | Face Price | 产品对外标价，所有角色可见 |
| 成本价 | Cost Price | 产品采购成本，仅采购/产品经理可见，销售字段级屏蔽 |
| 供货链 | Supply Chain | 供应商与产品的一对多供货追溯关系 |
| 上下架 | Active/Inactive | 产品上架后可被检索/推荐/方案引用，下架后仅存档 |
| 分享凭证 | Share Token | 对外分享链接的访问凭证，含密码/过期/次数控制 |

## 技术术语

| 术语 | 英文 | 释义 |
| --- | --- | --- |
| Business API | - | 业务层核心 API，所有业务操作统一入口，处理逻辑/校验/权限 |
| AI Service Adapter | - | AI 服务适配器抽象基类，解耦业务层与下游 AI 引擎 |
| RAG | Retrieval-Augmented Generation | 检索增强生成，AI 基于知识库检索后生成回答 |
| 向量召回 | Vector Recall | 通过向量相似度检索提供候选集，非最终事实数据 |
| 回查闭环 | Callback Loop | 向量召回候选 → Business API 回查关系型数据库确认真实数据 |
| Hybrid Search | - | 混合检索，向量相似度 + 关系型条件过滤的组合查询 |
| pgvector | - | PostgreSQL 向量扩展插件，支持向量相似度检索 |
| SSE | Server-Sent Events | 服务器推送事件，AI 流式对话的传输协议 |
| Tool Call | - | AI 发起的工具调用，经适配器标准化为统一格式 |
| 软删除 | Soft Delete | 标记 `is_deleted=true` 而非物理删除，保留数据可追溯 |
| UUID v7 | - | 时间有序的 UUID，利于 B-tree 索引性能 |
| ShareToken | - | 独立分享凭证表，收敛 token/密码/过期/次数/审计 |
| Visitor | 访客 | 通过分享链接访问 H5 的外部用户，通过设备指纹/openid 识别 |
| ShareLog | 分享访问日志 | 记录每次分享链接访问的审计日志 |
| FingerprintJS | 设备指纹库 | 前端 JS 库，生成浏览器唯一标识，用于访客识别 |
| 预签名 URL | Presigned URL | MinIO/S3 生成的带签名的临时下载链接，有时效性 |
| 乐观锁 | Optimistic Lock | 并发控制机制，通过 version 字段避免脏写 |
| HNSW | Hierarchical Navigable Small World | pgvector 支持的向量索引算法，高召回率 |

## AI 引擎术语

| 术语 | 释义 |
| --- | --- |
| FastGPT | 开源 RAG 框架，提供知识库问答与工作流编排 |
| Dify | 开源 LLM 应用开发平台，支持 Agent 与工作流 |

| 推荐理由 | AI 生成的产品推荐话术，含亮点提炼与行业语境修饰 |

## 角色术语

| 角色 | 释义 |
| --- | --- |
| 系统管理员 | 负责系统配置、用户与角色管理，拥有全部模块读写权限 |
| 采购/产品经理 | 负责产品参数配置、成本价维护、供应商管理，可见成本价 |
| 销售 | 负责产品检索、方案生成、报价、分享，严禁查看成本价 |
| 外部客户 | 通过分享链接访问 H5 页面的外部用户，无需登录，只读权限 |
| 访客 | 通过分享链接访问 H5 页面的外部用户，未登录，可能包含潜在客户 |

## 设计原则术语

| 术语 | 释义 |
| --- | --- |
| 数据解耦红线 | AI 能力中心永远不负责价格/库存/供应商等强准确性数据维护 |
| 双重防线 | 字段级权限在查询层 + 响应序列化层双重兜底校验 |
| 可插拔架构 | 通过适配器抽象，下游 AI 引擎可热切换，业务层零改造 |
| 四层架构 | 表现层 / 业务层 / 服务层 / 基础设施层 |
| 级联失效 | Cascade Invalidation，撤销分享时，share 与所有关联 share_token 同步失效的机制 |
| 双写一致性 | Dual-Write Consistency，业务数据与向量数据同步写入的事务保证策略 |
