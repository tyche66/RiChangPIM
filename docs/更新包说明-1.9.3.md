## 云端使用

1. 校验外层 SHA-256。
2. 在云端生产机备份 PostgreSQL 和 MinIO。
3. 解压更新包并检查 `git-head.txt`（应为 `fbe5856531735b3fd1fc9366316b947b5f146a61`）。
4. 按 `UPDATE_README.md` 构建前端和 backend/nginx 镜像，导出 `APP_VERSION=1.9.3` 与 `build_frontends.sh` 输出的同一组构建元数据。
5. 使用 `docker compose up -d --no-deps backend nginx` 更新服务；提醒引擎按需部署 worker（`docker compose -f docker-compose.yml -f docker-compose.worker.yml up -d worker`）。
6. 检查 migration head（`0022_reminders`）、版本接口与后台「系统管理 → 版本」页一致性，以及驾驶舱、客户/项目、内容工坊、提醒通知等本版新功能。
