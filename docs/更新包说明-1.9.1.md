# v1.9.1 更新包说明

更新包用于已有云端生产环境升级，包内只包含代码、配置模板、迁移、静态资源构建所需文件和更新手册，不包含业务数据。

## 生成内容

```text
RiChangPIM_update_v1.9.1_<timestamp>.tar.gz
RiChangPIM_update_v1.9.1_<timestamp>.tar.gz.sha256
```

包内根目录包含 `UPDATE_README.md` 和 `1.9.1-V-Log.md`。源码快照排除 `.env*`、`AI.env`、`embedding.env`、`backups/`、日志、volume、dist、node_modules、测试结果和缓存。

## 云端使用

1. 校验外层 SHA-256。
2. 在云端生产机备份 PostgreSQL 和 MinIO。
3. 解压更新包并检查 `git-head.txt`。
4. 按 `UPDATE_README.md` 构建前端和 backend/nginx 镜像。
5. 使用 `docker compose up -d --no-deps backend nginx` 更新服务。
6. 检查 migration head、版本接口、管理后台和媒体访问。
