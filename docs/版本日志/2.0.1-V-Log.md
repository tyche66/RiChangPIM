# RiChangPIM v2.0.1 版本日志

- 版本：`2.0.1`
- 日期：2026-11-03
- 迁移 head：`0043_proposal_item_custom_product`
- 基线：`v2.0.0`（迁移 `0040_announcement`）

## 新增

- 方案效果图：新表 `proposal_effect_image`、管理接口与管理板块；可绑定方案内产品或空间；分享页「效果图」板块按 空间/产品/整体 分组；产品详情页「搭配案例」连带展示。
- 方案内产品名称（`proposal_item.display_name`）：仅服务该方案，替代产品库名称对外展示。
- 方案内自定义产品（`is_custom` + `custom_product`）：不入产品库、仅本方案展示，图片随方案随用随删；不参与报价单。
- 已保存方案可「从产品列表选择」：筛选多选后回编辑页去重追加。
- 方案明细按楼层/空间折叠分组，默认展开。

## 修复

- 方案明细楼层/空间名称无法输入（重复更新覆盖异步 props）。
- 含超大平面图的方案打开时浏览器 `Out of memory`（缩略图改为后端 `w` 参数，16.99 MB → 41.5 KB）。
- 分享页/详情弹窗移除「自定义产品 · 仅本方案展示」副标题。

## 数据与权限

- 迁移：`0040_announcement` → `0041_proposal_item_display_name` → `0042_proposal_effect_images` → `0043_proposal_item_custom_product`。
- 无新权限码，无需手动数据回填；容器入口自动执行迁移与种子。

## 验证

- `vue-tsc --noEmit`：frontend、portal 通过。
- `scripts/build_frontends.sh`：admin + portal 构建通过。
- 迁移真实执行到 `0043_proposal_item_custom_product`（本地 888 栈实测）。
- 接口冒烟：方案内名称覆盖、自定义产品字段与图片、效果图绑定产品/空间、产品详情「搭配案例」回流、匿名分享白名单（无成本价）。
- 浏览器验收：楼层/空间输入可保存、含超大平面图的方案正常打开、分享页效果图分组与文案。

- 自定义产品不支持加入报价单（接口显式拒绝）。
