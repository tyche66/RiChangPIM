# RiChangPIM v1.9.1 Version Log

Release date: 2026-08-07

## Release Scope

This patch release consolidates the uncommitted product media import, AI / Knowledge Gateway, media access, Compose, and documentation changes after `v1.9.0`.

## Main Changes

- Product import accepts XLSX/XLSM embedded images and ZIP packages.
- Product images and scene images are classified, deduplicated by SHA-256, uploaded to MinIO, and bound to database records.
- Import failures are isolated per row with savepoints; successful rows are retained.
- Added `GET /api/v1/products/import-template` and expanded import result metadata.
- Updated OpenAI-compatible adapter, Knowledge Gateway planning, product tools, and recommendation behavior.
- Updated media APIs, frontend media/product/import views, nginx upload limits, and Compose settings.
- Added Chinese and English README files and current API, deployment, data-volume, MinIO, migration-bundle, and cloud-update documentation.
- Archived superseded design, planning, review, delivery, deployment, and duplicate AI documents under `docs/过时/`.
- Unified the MinIO application and backup bucket default as `ai-pim`.

## Compatibility

- Application version: `1.9.1`
- Database migration head: `0017_operation_log_username`
- No new Alembic migration is introduced by this release.
- Existing PostgreSQL, Redis, and MinIO volumes must be preserved during an update.
- The cloud update package contains no production database, MinIO objects, Redis data, environment secrets, or backups.

## Upgrade Notes

1. Back up PostgreSQL and MinIO before replacing application containers.
2. Build both frontends with `bash scripts/build_frontends.sh`.
3. Export matching `APP_VERSION`, `BUILD_ID`, `GIT_COMMIT`, `BUILD_TIME`, and `APP_ENV=production` values before building backend and nginx images.
4. Recreate only backend and nginx with `docker compose up -d --no-deps backend nginx`.
5. Verify `/api/v1/health`, `/api/v1/version`, `/admin/`, product import, images, scene images, and MinIO-backed downloads.

## Package Types

- Full migration bundle: source, Git bundle, environment originals, PostgreSQL logical dumps, PostgreSQL/MinIO/Redis volume archives, Docker inspection data, checksums, and recovery documentation.
- Cloud update package: source and update instructions only; no business data or secrets.

The exact package filename, Git commit, build timestamp, file sizes, and SHA-256 values are recorded in each generated package manifest.
