# RiChangPIM v2.0.0 版本日志

- 版本：`2.0.0`
- 日期：2026-11-01
- 迁移 head：`0040_announcement`
- 分支：`release/2.0.0`

## 新增

- FR-1：分享页通用图片查看器，主图 + 场景图统一画廊。
- FR-2：方案创建/编辑独立页面，商品明细响应式栅格、只读平面图卡、未保存拦截。
- FR-3：全局设置后端、管理页、Logo 强缓存、门户品牌接入、分享/报价默认值。
- FR-4：公告表、管理页、匿名 `/active`、后台/门户弹窗、Markdown 安全渲染。
- VR-1：门户浅色视觉规范、强调色、页眉装饰线。
- 双端统一视频分栏登录页。
- 方案详情页分享链接与二维码复用。
- 分享页全屏图片裁切修复。
- 门户结果页宽度、比较表粘性滚动、来源折叠、产品卡与库存展示优化。
- 后台「销售工作台」分组，分享管理迁入该分组。

## 数据与权限

- 迁移：`0039_system_setting` → `0040_announcement`。
- 新权限：`setting:view`、`setting:edit`、`announcement:view`、`announcement:manage`。
- 无需手动数据回填；容器入口自动执行迁移与种子。

## 已知限制

- 外部 AI 服务超时会令门户查询停留在处理中，与本版代码无关。
- 门户登录视频依赖外部 CDN，失败时回落渐变背景。
- 深色主题保持原配色，不应用本期浅色强调色规范。
