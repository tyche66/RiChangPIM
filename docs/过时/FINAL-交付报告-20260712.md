## 四、关键决策记录

| 决策项 | 决策结果 | 决策理由 |
| --- | --- | --- |
| 表数量口径 | 23 张 | 实际 DDL 建表数（用户4+产品6+资产3+销售4+审计6含visitor） |
| 权限矩阵 cost_subtotal/profit_margin | 移除，V2 再补 | V1 不做利润分析，避免过度设计 |
| 单/多角色 | MVP/V1 单角色，V2 多角色 | 当前业务场景单角色够用，避免过早引入复杂度 |
| pgvector 维度 | 1536（OpenAI ada-002），可配置 | 锁定 MVP 默认值，切换时 ALTER |
| 双写事务边界 | MVP 同步双写，V1+ 异步补偿 | MVP 数据量小，一致性优先 |
| 文件类型 | 补充 doc/docx 支持 | 业务需上传 Word 版产品手册 |
| MVP 建表策略 | 23 张表全部建 | 避免后续频繁 DDL 迁移，建表与启用解耦 |
