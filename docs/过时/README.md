# 过时文档归档

本目录保存已被当前实现、部署方式或版本计划替代的历史文档，仅用于审计、追溯和理解设计演进。

目录内文档不作为当前开发、部署、接口或恢复操作指南。当前执行口径请从仓库根目录 `README.md`、`README-OPS.md` 和 `docs/` 当前文档开始查阅。

## 归档规则

- 设计概念、历史路线图、阶段性交付报告和旧部署方案进入本目录。
- 历史文档保留原始内容，文件名追加版本或日期标识，不覆盖历史记录。
- 当前仍维护的产品需求、HLD、ERD、BPM、开发规范、测试计划保留在 `docs/` 根目录。
- `AI-Docs/` 是独立的可插拔 AI 设计、规划和扩展目录，不属于本归档目录。
