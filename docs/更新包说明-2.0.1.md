## 云端使用

1. 校验外层 SHA-256。
2. 在云端生产机备份 PostgreSQL 和 MinIO。
3. 解压更新包并检查 `source/git-head.txt`（应为 `fadfd0d`，tag `v2.0.1`）。
4. 按 `UPDATE_README.md` 构建前端和 backend/nginx 镜像，导出 `APP_VERSION=2.0.1` 与 `build_frontends.sh` 输出的同一组构建元数据。
5. 使用 `docker compose up -d --no-deps backend nginx` 更新服务。
6. 检查 migration head（`0043_proposal_item_custom_product`）、`/api/v1/health` 与后台「系统管理 → 版本」页一致性，并验收方案效果图、方案内名称、自定义产品、从产品列表选品、明细折叠与超大方图方案不再崩溃。
